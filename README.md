R code for analysis linked to the project (research article) "Parental contributions to offspring skin microbiota remain detectable after metamorphosis".

Description of the data: This data was collected for a microbiome tracking experiment where we describe the relevance of verticla transmission during tadpole transportation behaviours (parental care performed by the adult male). We set three treatments (normal transport, no transport and foster transport) to determine the effect of transportation on the seeding of skin microbiome of the offspring.
